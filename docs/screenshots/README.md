# Скриншоты для README

Здесь лежит скриншот приложения, который подхватывает `README.md`:

| Файл | Описание | Размер |
|------|----------|--------|
| `app.png` | Главный экран (вкладка «Настройки») | ~1080×1920 |

## Как обновить скриншот

1. Запустите приложение на телефоне/эмуляторе
2. Сделайте скриншот нужного экрана
3. Переименуйте в `app.png` и положите в эту папку (перезаписав старый)
4. Ссылка в `README.md` относительная — ничего менять не нужно

Дополнительные скриншоты (история, логи, «О приложении») можно добавлять
отдельными файлами и вставлять их в `README.md` по аналогии.
