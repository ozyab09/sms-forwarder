# Скриншоты для README

Положите сюда 3 скриншота приложения:

| Файл | Описание | Размер |
|------|----------|--------|
| `settings.png` | Экран настроек (токен, Chat ID, прокси, переключатели) | ~1080×1920 |
| `test.png` | Диалог проверки связи («Проверка…», успех/ошибка) | ~1080×1920 |
| `status.png` | Статус сервиса (запущен/остановлен, счётчик, лог) | ~1080×1920 |

## Как сделать скриншоты

1. Запустите приложение на телефоне/эмуляторе
2. Сделайте скриншоты нужных экранов
3. Переименуйте и положите в эту папку
4. Они автоматически подхватятся в README.md (ссылки относительные)
